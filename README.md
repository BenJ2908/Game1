# Breachline Arena

A fast, original 5v5 team-deathmatch arena shooter that runs in the browser. One file, no build step.

## Play

Open `index.html` in a desktop browser (needs an internet connection the first time, to load three.js and fonts from a CDN). Phones and tablets get touch controls with auto-fire.

## Controls

| Action | Key |
| --- | --- |
| Move / sprint | WASD / Shift |
| Crouch, slide while sprinting | C or Ctrl |
| Jump | Space |
| Fire / aim | Left / right mouse |
| Reload | R |
| Swap weapon | 1, 2 or mouse wheel |
| Stim heal | Q |
| Frag grenade | G |
| Pulse scan (see hostiles through walls) | F |
| Strike run (earn 500 streak score in one life) | X |
| Scoreboard / pause | Tab / Esc |

## What's in it

- 150 health with a manual stim heal, hitmarkers, headshots, kill feed, medals and score popups
- Three loadouts (assault rifle, SMG + shotgun, sniper) and three bot skill levels
- Bots that path around the map, react, strafe and fight each other
- Minimap, damage direction indicators, recoil, weapon sway, tracers, synthesised sound
